# Privacy policies — anyethernet

Publisher: [anyethernet](https://github.com/anyethernet)

App privacy policies live in one folder per app so new titles can be added without changing the site root.

| App | Path | URL |
| --- | --- | --- |
| Webcam & Screen Saver | [`Webcam_Saver/`](./Webcam_Saver/) | https://anyethernet.github.io/privacy-policy/Webcam_Saver/ |

## Add another app

1. Create a folder named like `Your_App_Id`.
2. Put `index.md` (or `README.md`) with that app’s privacy policy.
3. Add a row to the table above.
4. Push to `main`. GitHub Pages will publish at `https://anyethernet.github.io/privacy-policy/Your_App_Id/`.
